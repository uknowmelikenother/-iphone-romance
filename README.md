# 나의 iPhone · 恋爱手机模拟器

这是可直接上传 GitHub 的纯静态项目。无 npm 依赖、无 AI 接口、无后台、无真实账户登录、无真实支付或消息发送。所有人物关系及聊天均为虚构剧情。页面语言为韩语。

## 最简单的使用方式

1. 解压整个 ZIP。
2. 保留 `index.html`、`style.css`、`app.js`、`content.js` 与 媒体文件 的相对位置。直接双击 `index.html` 可以试用，视频播放取决于浏览器对本地文件的支持。
3. 上传解压后的所有项目文件到 GitHub 仓库；`index.html` 要在仓库根目录，不能只上传 ZIP，也不能只复制 HTML。
4. 如果需要公开网址，可用 GitHub Pages 发布该静态仓库，或把同一个仓库交给静态托管平台。不要上传任何账号密码或密钥；本项目不需要密钥。

本地服务器方式（电脑安装 Python 后）：

```sh
cd iphone-romance
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。Node.js 用户可运行 `node test.cjs` 做逻辑与素材检查。

## 文件用途

- `index.html`：网页入口和全屏图片查看器。
- `style.css`：手机、App 界面和响应式样式。
- `app.js`：页面切换、分支对话、存档、通知、图片与视频交互。
- `content.js`：人物、帖子、短信、备忘录、固定聊天和男主分支剧情，日后主要编辑这里。
- 媒体文件：已经包含本次提供的正式图片与三个 MP4 视频，使用英文文件名，部署后不会依赖聊天附件地址。
- `asset-manifest.json`：原始附件名与项目文件名的精确对照。
- `SPEC.md`：需求清单、已实现功能与边界，供后续 Codex 接手。
- `test.cjs`：不需要安装依赖的自动检查。

## 存档与安全

姓名、男主进度、未发送完的剧情队列、点赞、收藏和图片爱心保存在当前浏览器的 localStorage。不同网址、浏览器或设备不会共享存档；无痕模式或清除网站数据可能移除存档。

所有输入的玩家姓名在写入页面时转义。项目没有联网 API、没有调用媒体设备权限、没有需要保密的环境变量。分享帖子按钮仅复制本站帖子的地址，不会向他人发送消息。

不要把源码中的测试通过理解为所有手机都已验证。此次自动检查覆盖页面生成、全部分支选项、刷新续传、姓名转义与替换、素材路径、帖子分组和金额；最终手机浏览器中的布局、手势及有声视频仍需实际试玩。内置浏览器若限制视频播放，可用系统浏览器访问同一网址。
